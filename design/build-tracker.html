Phase 01

Data layer

6 / 6 done

Built first and on its own. Nothing outside src/storage/ touches IndexedDB, so when a server is added later, only that directory changes.

Schema, sync-ready from day one

Every note and category carries id (UUID v4), createdAt, updatedAt, syncedAt, deletedAt. Deletes are soft only — nothing is ever removed from disk, so a deletion can still be replayed to a server.

Done

Storage module, four verbs

get · put · list · remove over IndexedDB via Dexie. put stamps updatedAt and clears syncedAt; remove writes a tombstone rather than deleting.

Done

Export

One JSON file: every note, every category, the settings and a schema version. Filename carries the date — self-notes-2026-09-15.json — so backups sort and never overwrite each other.

Done

Import, merge and never overwrite

Unknown id imports. Identical record skips. Same id with different content keeps both — the incoming copy under a fresh id, with replies rewritten to follow their re-homed parent. Summary shown after: imported / already here / kept alongside.

Done

Round-trip test

Export → wipe → import restores byte-identical state, tombstones and reply links included. Also proven: a second round trip changes nothing, and two fresh installs merge without duplicating their default categories.

Done

Monotonic timestamps

Three thoughts fired off in one second used to sort arbitrarily and scramble the thread. Each collision now advances a millisecond, so createdAt is strictly increasing and order is never in doubt.

Done
Phase 02

The app

12 / 12 done

Layout is fixed across both skins: category rail on the left, the selected page in the middle, the chat with yourself on the right.

Two skins, user-selectable

Desk and Yakan, plus “follow system” which picks Desk in light mode and Yakan when the device goes dark. Colour, corner radius and typeface all swap from one data-skin attribute.

Done

Composer — category required

Chips, then the Schedule and Urgent toggles, then send. Enter sends, Shift+Enter makes a line. Japanese IME conversion is left alone, so Enter mid-conversion never fires a half-finished note.

Done

Chat stream, all categories

One running conversation with yourself for the day, each note tagged with its category colour — as you chose.

Done

Category page

Urgent notes pinned across the top quarter in red; below them the thread split by day, newest at the bottom. Clicking a pinned note jumps to it in the thread.

Done

Added notes as replies

A note added onto another lands directly beneath it, on the opposite side, quoting the original — the reply bubble from any chat app. It inherits the parent’s category so the two can never drift apart.

Done

Note menu, three ways in

Long-press on touch (480 ms, cancelled by a scroll), hover ··· and right-click on desktop. Add note, urgent, calendar on/off, change date, move category, delete.

Done

Home calendar, week & month

Only original notes appear — an added note belongs to its parent, not to a day. Each sits in a message bubble; tapping one opens its category page and highlights it.

Done

Settings

Phone layout
